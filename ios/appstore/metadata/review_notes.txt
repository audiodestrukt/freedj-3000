OpenDeck DJ is a standalone single-deck DJ player; no external hardware or account is needed to review it. A demo track is pre-loaded — tap PLAY/PAUSE, use the jog wheel, tempo fader, CUE, LOOP IN/OUT and the on-screen BROWSE / PERFORM keys.

To load your own music: copy audio files into Files → On My iPhone / On My iPad → OpenDeck DJ, then tap BROWSE (or the FILE key), turn the BROWSE knob and press it to LOAD.

On iPhone (new in 0.2) the app is landscape-only and has two pages: SCREEN (the player display with BROWSE, CUE and PLAY beside it) and CONTROLS (jog wheel, tempo fader, loops). Flip with the page button in the bottom margin or a two-finger swipe up/down.

New in 0.3 (iPad): MENU (the on-screen MENU key) → SCREEN switches to a second player layout with its own full faceplate. On its faceplate, hold MENU for a second to reach the menu again (a short press opens the previously loaded tracks); set SCREEN back to switch layouts again. On iPhone the setting stays on the original layout.

On first launch iOS asks for Local Network permission. This is used only for Pro DJ Link on the local network: beat-syncing with Pioneer CDJ/XDJ players if any are present, and letting those players browse and load the app's music folder. Denying it leaves every other feature working. Nothing is sent off the device.

The app carries the com.apple.developer.kernel.increased-memory-limit entitlement for an optional feature: separating a track into stems (drums, vocals, the rest) on the device. The first time the user opens the STEMS panel (the STEMS key above the screen), the app downloads one Core ML model file (about 290 MB, HTDemucs, MIT licence) from a fixed address on Hugging Face, checks it against a pinned SHA-256 checksum, and keeps it in Application Support, excluded from backup. The download is data (model weights), not code. No user data is sent anywhere: it is a plain file download, and the separation runs entirely on the device. On a device without enough memory the stem keys say NEEDS MORE MEMORY and nothing is downloaded. To try it: with the demo track loaded, tap STEMS, wait for the download shown across the panel to finish, and the track splits; the stem keys then mute and level drums, vocals and the rest.
